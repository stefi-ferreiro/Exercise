Colors

A color palette is a carefully chosen set of colors that define a brand’s visual identity. It creates harmony, consistency, and emotional impact across designs. When used effectively, it guides attention, improves readability, and strengthens the overall user experience.

Gradients

A gradient is the gradual blending from one color to another. Gradients add a new dimension, help objects stand out, and create new expressions of the brand palette.

Foundations Typography

Typography

Inter is the primary typeface for the Teacher experience, chosen for its clarity, neutrality, and strong performance across information-dense interfaces.

Its clean forms and highly legible structure support the way teachers consume information: analysing student progress, interpreting metrics, reviewing rubrics, and making decisions based on data.

The type scale creates clear hierarchy and structure, helping users quickly distinguish between key information, supporting content, and actions.

Foundations Shadows

Shadows

Shadows allow you to add depth and realism to designs by positioning elements on a z-axis.

Foundations Blurs

Blurs

Background blurs are often used stylistically in modern UI design. However, just like shadows, they allow you to add depth and realism to designs by positioning elements on a z-axis.

Foundations Primitives

Primitives

Primitive variables are the raw color, spacing, radius, size, and stroke values in the MathVoice Figma library. Semantic tokens alias these primitives.

Foundations Semantic

Semantic

Semantic variables map primitives onto component roles such as buttons, inputs, sidebar, and text. Use these names in product UI instead of raw palette steps.
